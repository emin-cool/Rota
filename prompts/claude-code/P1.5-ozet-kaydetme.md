# P1.5 — Aktivite özeti + kaydetme

**Kontrol:** Aktivite bitince özet açılıyor, Supabase'de `activities` satırı var, puan verince rotanın ortalaması güncelleniyor.

```text
design/stitch/results-live-summary.html Ekran 3'e göre app/activity/summary.tsx ekranını yap.

1. Harita (izlenen yol), istatistik ızgarası (mesafe, süre, ortalama tempo, tırmanış, tahmini kalori), başlık düzenleme, görünürlük seçimi (herkese açık / takipçiler / sadece ben, varsayılan takipçiler).
2. Aktiviteyi activities tablosuna kaydet. Kullanıcının privacy_zone'u varsa track'in o bölgedeki kısmını sunucu tarafında kırp (trigger veya Edge Function).
3. Fotoğraf ekleme: expo-image-picker → sıkıştır → Supabase Storage → route_photos (rota varsa).
4. Rota ile yapıldıysa: 5 yıldız + etiket çipleri + kısa yorum → route_reviews (is_verified = true).
5. Paylaş: harita + istatistik görselini oluştur (react-native-view-shot) ve sistem paylaşım menüsünü aç.
6. Kayıt başarısızsa yerelde tut ve internet gelince tekrar dene.

TASKS.md'de P1.5'i işaretle, commit mesajı öner.
```
