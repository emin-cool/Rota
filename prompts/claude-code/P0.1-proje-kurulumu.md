# P0.1 — Proje kurulumu

**Ön koşul:** Windows kurulumu tamam, `design/stitch/` içinde en az `home-map.html` ve `DESIGN.md` var.
**Kontrol:** `npx expo start` → telefonda 5 sekmeli boş uygulama açılıyor.

```text
CLAUDE.md ve docs/03-teknik-mimari.md dosyalarını oku.

Bu klasörde (mevcut dosyaları silmeden) Expo + TypeScript (strict) + Expo Router ile React Native projesi kur. NativeWind'i yapılandır. CLAUDE.md'deki klasör yapısını oluştur.

Alt menüde 5 sekme olsun: Harita, Keşfet, Kaydet (ortada yükseltilmiş büyük + butonu), Akış, Profil. Şimdilik ekranlar sadece başlık göstersin.

design/stitch/ klasöründeki HTML'leri ve DESIGN.md'yi oku; renk, yazı tipi, boşluk ve radius değerlerini src/theme/tokens.ts dosyasına çıkar ve tailwind.config'e bağla. Plus Jakarta Sans fontunu expo-font ile yükle.

Temel UI bileşenlerini src/components/ui altında oluştur: Button (primary/secondary/ghost), Card, Chip (seçilebilir), Text başlık stilleri, BottomSheet sarmalayıcısı.

src/i18n/tr.ts dosyasını oluştur ve sekme adlarını oraya taşı. ESLint + Prettier ayarla. .gitignore'a .env ekle, git init yap.

Bitince: Windows'ta uygulamayı telefonda nasıl çalıştıracağımı adım adım yaz, TASKS.md'de P0.1'i işaretle ve commit mesajı öner.
```
